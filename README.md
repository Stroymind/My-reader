# 我的书房

个人的阅读与知识工作台。书、阅读进度、书签、划线、批注和笔记都只保存在你自己的设备上，不会上传到服务器，也不需要注册账号。

可以在手机浏览器里打开，也可以安装真正的 Android 应用。两边是同一套界面。

从一次阅读开始：把句子留下来，整理成笔记，再把笔记连成自己的知识网络。需要时，可以让模型解释或回答；没有密钥时，仍然可以用本地抽出的要点。

## 在线使用

https://stroymind.github.io/My-reader/

在浏览器里选择“添加到主屏幕”，得到的是网页快捷方式。要装成手机上的普通应用，请用下面的安装包。

## 安装 Android 应用

安装包由仓库的 GitHub Actions 自动构建。请只从本仓库下载。

1. 用手机或电脑打开：<https://github.com/Stroymind/My-reader/actions/workflows/android.yml>
2. 点开最近一次绿灯通过的“构建 Android 安装包”。
3. 在页面底部的 Artifacts（构件）里下载 `shufang-android`。
4. 解压后得到 `shufang.apk`。手机上如果不会自动解压，用文件管理器打开这个 zip。
5. 点 `shufang.apk` 安装。

如果系统提示不能安装未知应用：

1. 打开系统设置，搜索“安装未知应用”或“未知来源”。
2. 找到你用来打开安装包的应用（浏览器或文件管理器），允许它安装应用。
3. 再点一次 `shufang.apk`。

装好后，桌面上会出现“我的书房”。导入的书保存在应用里，没有网络也可以接着读。

更新时直接安装新的 `shufang.apk`，不用先卸载。这个安装包的签名密钥随仓库公开，只用于自行安装，不要拿它上架应用商店。

打上 `v` 开头的版本标签时，Actions 也会把同一个 APK 附到 GitHub Release。

## 导入书籍

点右上角“导入”，可以一次选中多个文件。

支持这些格式：

- EPUB（含 EPUB2 / EPUB3、子目录、不规范网页和国标编码。有数字版权保护的书会说明无法打开）
- PDF
- TXT（自动识别 UTF-8 和 GBK）
- HTML、HTM、XHTML
- ZIP 压缩包。包里可以有很多本书，也会继续识别上面的格式

同一本书再导入一次不会重复添加。

## 阅读

- 打开应用先看到书库。可以搜索、按最近阅读、最近导入或书名排序。右上角可以切换浅色、深色或跟随系统，这和书页里的纸张、护眼、夜间是分开的。
- 打开一本书之后，它会记为最近阅读，回到书库时排在最前面。不用先去选排序。
- 英文书默认中英对照：上面仍是原文，下面是这一页的中文。只翻译当前这一页，并记在本机。中文书不会翻译。排版里可以把「对照」关掉，只看原文。
- 放大文字会按手机宽度重新换行，不会把字缩放到屏幕外面。双指张开即可放大，排版里也可以调字号。
- 点屏幕左侧或右侧翻页，点中间打开菜单。
- 右上角 ☆ 添加或取消当前页的书签。
- 长按一段文字，或点右上角的笔形按钮：可以划线、批注、摘录、让 AI 解释，或复制。
- 复制会放进系统剪贴板，同时在本机留下这条摘录。
- 批注和摘录可以写一句笔记，也可以留空，还可以加上标签。
- 阅读菜单里的“划线”查看这本书的划线、批注和摘录。右上角「摘录」看全部。
- 这些内容都保存在这台设备上。
- 删一本书：在封面上长按，确认即可。要删好几本，在书库底部的「整理」里点要删的那几本，再点「删除所选」。没点到的书不会出现删除标记。

## 知识库

划线、批注、摘录和复制都会进入「知识」。也可以写一条不依附于某本书的笔记，或从「写一次判断」开始一条分成问题、材料、判断的笔记。

- 笔记可以改标题、正文和标签。正文里写 `[[另一条笔记的标题]]`，保存时会连到同名笔记。
- 也可以在笔记底部直接选择另一条来建立或断开关联。
- 「复制大纲」把当前筛选出来的笔记变成 Markdown，方便贴进写作。
- 删掉一条来自书里的笔记时，书上对应的划线也会去掉。

## 图谱

「图谱」把笔记画成一张可以拖动、缩放的网。实线是你建立的关联，虚线是相同的标签。点一个节点，可以只看它周围的笔记，或回到原文。

## AI

「AI」里可以填写兼容 OpenAI 的接口地址、模型名和密钥。密钥只保存在这台设备上，不会写进仓库。

没有密钥时，解释会给出本地抽出的要点，不会把选中的文字发出去。配好之后，可以对选中文字做解释和提问，并把结果存成笔记。

## 隐私

书、进度、书签、摘录和笔记只存在这台设备上。应用不会把书上传到公开网址，也不会改动网盘的分享设置，不需要 Readwise 或其他账号。只有在你自己保存了模型密钥并点击解释或提问时，选中的那段文字才会发到你填写的接口。Android 版已关闭系统自动备份，避免书被系统备份带走。

## 还没做

完整的写作与决策工作区、流式输出、多家模型预设、更稳的概念抽取、云同步，以及笔记很多时的分层图谱，都留到后面。现在的「应用」是把笔记复制成大纲，外加一条判断模板。

## 网页版和推文转文字

网页版和 Android 版共用同一套阅读功能。`tweet-to-text/` 是另一个独立的小工具，不受这个 Android 应用影响，GitHub Pages 上的网页版也会继续发布。

## 自己构建安装包

`.github/workflows/android.yml` 会在推送到 main、打开拉取请求，以及手动运行时构建 APK，并把它传到该次运行的构件里。

本机构建需要 Node.js 22、JDK 21 和 Android SDK 36：

```bash
npm ci
npm run android:release
```

安装包在 `android/app/build/outputs/apk/release/`。签名用的是仓库里的公开钥匙，只为了让每次打出来的包都能覆盖安装。
